📊 Database Overview

Total Tables: 5 (including Django's User table)

Models:

  • User - Django's built-in authentication model
  • Recipe - Caches API recipes from Spoonacular
  • UserRecipe - Junction table linking users to saved recipes
  • CreatedRecipe - User-generated original recipes
  • RecipeComment - Comments on API recipes

🔗 Key Relationships

  • User → UserRecipe: One user can save many recipes
  • User → CreatedRecipe: One user can create many recipes
  • User → RecipeComment: One user can write many comments
  • Recipe → UserRecipe: One recipe can be saved by many users
  • Recipe → RecipeComment: One recipe can have many comments

✨ Special Features

  • Unique Constraint: UserRecipe has unique_together(user, recipe) to prevent duplicate saves
  • Cascade Delete: All foreign keys use CASCADE deletion
  • Rating System: 0-5 star ratings on UserRecipe and RecipeComment
  • Sharing Feature: Both UserRecipe and CreatedRecipe can be shared to community feed
  • API Caching: Recipe model reduces API calls by caching Spoonacular data
  • Cloud Storage: CreatedRecipe uses Cloudinary for image uploads
